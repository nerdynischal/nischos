# Project audit and refactor

21 November 2026

The local project passes its production checks after the dependency upgrades and
the fixes below. This review covered the application source, content boundaries,
window and navigation state, image handling, media generation, database policy
definitions, and deployment configuration. Existing unfinished About content was
preserved. No database content or deployment was changed during the audit.

## Findings fixed

| Area | Finding | Result |
| --- | --- | --- |
| Content links | Remote project website/source links bypassed the validation already applied to settings links. | Shared HTTP/HTTPS validation now covers both content models. Unsupported schemes and malformed links become unavailable actions. |
| Request lifecycle | Projects, note summaries, and settings queries had no explicit deadline. One stalled query kept the overall connection indicator loading. | All four content query types share a ten-second abort deadline with timer cleanup. Independent collection fallback behavior is retained. |
| Client initialization | A rejected lazy Supabase-client import remained cached permanently. | Failed initialization clears the cached promise so later requests can retry. |
| Carousel selection | After a remote screenshot list shrank, Previous decremented the stale stored index instead of the visible index. | Navigation starts from the currently displayed, clamped index. |
| Image failures | While a replacement image decoded, failure of the old displayed image could be attributed to the newly selected screenshot. Only one failed asset was remembered. | Errors identify their source asset. Failed assets retain fallbacks when revisited; late decode failures after selection changes are ignored. |
| Image descriptions | Updated alternative text for an unchanged image URL remained stale in the displayed frame. | The current asset uses its latest description without waiting for another image transition. |
| Remote artwork | Remote SVG project icons fell back to placeholders in the preview even though their public endpoints returned HTTP 200. | Three SVG icons now have checked-in local mirrors. The underlying remote/browser failure was not independently established. |
| Live asset identity | Workout Board and Pricewatch used live asset URLs absent from the local media/description maps. | Byte-for-byte comparisons established explicit aliases to checked-in images. Live screenshots now share responsive variants and authored descriptions. |
| Generated media | Encoder upgrades left obsolete content-hashed variants in the output directory, and Vite copied them into deployments. | Generation removes obsolete hash-named variants after saving the current manifest. It preserves source artwork and unrelated files. |
| Diagnostic script | A blank publishable key suppressed a valid legacy key; checks could also wait indefinitely. | The Supabase check trims keys before choosing its fallback and aborts stalled requests. |

## Refactoring

- Extracted About list/detail navigation, mobile titles, and focus restoration into
  `useSettingsNavigation`. The renderer no longer owns those effects and state
  transitions. A selected value must still exist in the current content list.
- Consolidated web-link validation in `externalUrl`, request deadlines in
  `withRequestTimeout`, and local/remote image identity in `mediaSource`.
- Kept image-failure callbacks stable so unrelated parent renders do not restart
  image decoding. Existing window geometry, lazy readers, note caching, motion,
  and design tokens remain in place.
- Added regression coverage for the defects and for complete media references.
  No new runtime dependency was needed for this refactor.

## Verification

- Clean `npm ci` succeeded and reported zero vulnerabilities.
- `npm run check` passed: seven project manifests, five dock positions, CSS token
  validation, lint, **202 tests across 43 files**, TypeScript, and production build.
- A separate production build with `VITE_BASE_PATH=/nischos/` passed. Its browser
  preview loaded project artwork and carousel images under the correct subpath,
  with authored Pricewatch descriptions and no captured console warnings/errors.
- Public Supabase reads succeeded for seven projects, one note, and five settings
  sections. This verifies public reads, not the absence of every possible write
  policy in the live database. Checked-in SQL grants public clients read access
  and revokes table writes.
- Browser checks covered unlock, connected content, About/Values forward/back
  navigation and focus, remote Notes body loading, carousel controls, window
  arrangement, archive loading, and image-dialog isolation/focus restoration.
- Responsive checks included 320px mobile navigation, 768px and 1024px project
  bounds without horizontal frame overflow, and a 1440px desktop. Both desktop
  themes were visually checked. All ten desktop artwork images loaded after the
  media fixes. This was scoped browser verification, not every journey at every
  width and theme.
- Removed 325 obsolete generated variants. Rounded local disk usage fell from
  **22 MB to 11 MB** for optimized artwork and **54 MB to 42 MB** for the build.
  These are directory sizes, not network-transfer or page-speed measurements.
- Local runtime: Node 24.14.0 and npm 11.9.0. Node 22 and 26 were not executed.
